# こんにちは、Kyo1r0 です 👋

**Kyoichiro Takemura** — ゲームの研究・ゲームAI・競技プログラミングが好きな学生エンジニアです。
組合せゲーム（石取りゲーム / Nim）から囲碁まで、「ゲームを計算機で解く・遊ぶ」ことをテーマにいろいろ作っています。

## 🎯 興味のあること

- 🧮 **組合せゲーム理論** — 石取りゲーム・Nim の解析から囲碁の研究へ
- ⚫⚪ **囲碁 / ボードゲームAI** — 小路盤の囲碁、三次元将棋など
- 🏆 **競技プログラミング** — AtCoder に取り組んでいます
- 🛠️ **ちょっと便利なツール作り** — 日々の困りごとを小さく解決する
